## Результат

| Показатель | Значение |
|---|---|
| Число вершин графа ʋ | 38 |
| Вершины выбора | 7, 10, 12, 14, 21, 24, 26, 30, 31, 34 |
| Абсолютная граничная сложность Sa | 77 |
| Относительная граничная сложность So = 1 − (ʋ − 1)/Sa | 1 − 37/77 = 0,5195 |

## Как построена схема

- Каждому блоку схемы соответствует один оператор программы, номер блока — номер вершины графа.
- Каждый цикл `for` изображён с инициализацией, проверкой и изменением переменной цикла (например, блоки 6, 7, 18).
- Оператор `match` изображён вложенными друг в друга символами «Решение» (блоки 24, 26).
- Переходы между колонками выполнены соединителями 1–4.
